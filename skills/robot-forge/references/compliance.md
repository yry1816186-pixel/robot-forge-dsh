# 安全、合规与供应链 v2.0

> 本文件是工程自检清单，**不是法律意见**。标准号与法规会更新，发布前按目标市场查最新版本并请有资质的人复核。
> 九类旗标由 `rf_intake` / `rf_check` 自动识别：battery、mains、motion、laser、privacy、network、children、outdoor、medical。
> 触发后必须同时具备：`compliance` 块、`docs/07` 对应内容、风险表条目、必要时 `security` 块。

## 1. 九类旗标与必写内容

| 旗标 | 触发 | docs/07 必写 | 常见标准/做法（参考） |
|---|---|---|---|
| battery | 锂电/18650/LiPo/电池 | 过充过放、短路穿刺、热失控、保险丝、充电器、存放温度 | GB 31241（便携式锂电，参考）、UN38.3（运输）、保护板、防火袋 |
| mains | 220V/市电/插座 | 隔离、漏保、接地、防水接头、断电挂牌、成品电源优先 | GB 4943.1（信息技术设备，参考）、CCC、漏电保护 |
| motion | 电机/舵机/机械臂/桨 | 限位、急停、断电泄力、人员隔离、失联停机 | 软/硬限位、双通道急停、护罩、警示标识 |
| laser | 激光/LiDAR | 等级、护目、避免直视、扫描区隔离 | GB 7247.1（激光产品，参考）、Class 1 优先 |
| privacy | 摄像头/麦克风/录音 | 最小采集、本地优先、物理遮挡、告知与删除 | 个人信息保护法、告知同意、默认不录不传 |
| network | WiFi/蓝牙/云端/App | 鉴权、默认密码变更、OTA 签名、最小暴露面 | 强口令、TLS、签名 OTA、关端口 |
| children | 儿童/学生/教育 | 小零件、低压、教师监护、防误吞 | GB 6675（玩具，参考）、年龄标识、成人监护 |
| outdoor | 户外/防水/水下/船 | IP 等级、排水、防凝露、失联回收 | IP54 起步、O 圈、透气压差膜 |
| medical | 医疗/康复/诊断 | 明确非医疗器械、不得诊断治疗 | 不宣称疗效；涉及医疗需持证评估 |

**判定**：有触发但没写 `compliance` → CST-10；docs/07 缺关键内容 → CST-11；联网但没 `security` → CST-12。这些是 warning，但发布评审必须解释清楚或修掉。

## 2. battery（锂电）

- 只用**带保护板的成品电池组**；不买裸电芯自己点焊；不用“航模电池”给桌面设备；
- 保险丝/船型开关串在正极总回路；反接保护与防呆插头；
- 充电器必须匹配化学体系与串数（2S 用 8.4 V 平衡充）；充电有人看管；
- 鼓包、破皮、发热、异味立即断电移到室外；不用水浇；
- 存放 3.8 V/节、阴凉干燥、每 3 个月补电；
- 运输/寄样参考 UN38.3；>100 Wh 的电池上飞机/快递有额外限制。

## 3. mains（市电）

- 零基础项目优先用**成品 5V/12V/24V 电源适配器**，不要自己焊 220 V；
- 必须自己做市电时：隔离变压器、漏保、接地、熔断器、防水接头、断电挂牌；
- 金属外壳接地；强弱电分开走线；爬电距离/电气间隙按标准；
- 潮湿、户外、儿童可触及的场景禁止裸市电。

## 4. motion（运动与夹伤）

- 软限位 + 硬限位（机械挡块/限位开关）；上电先归零/自检；
- 急停切断执行器使能，不是只发“停止”命令；急停后手动复位；
- 失联/看门狗 1 s 内停机；堵转电流/温度保护；
- 人员隔离：护罩、光幕、安全距离；调试时架空/断使能；
- 写明“不得载人/不得靠近儿童/长发围巾远离”。

## 5. laser / privacy / network

- 激光优先 Class 1 封闭式；否则护目镜、钥匙开关、警示、扫描区隔离；
- 摄像头/麦克风：默认关闭、物理挡片/断电、采集指示灯、告知与删除、最小化保存；
- 联网：默认只监听 127.0.0.1；局域网访问要配对码/令牌；关默认口令；OTA 必须签名并可回滚；
- 不上传原始音视频；云端功能显式开启并写隐私政策。

## 6. children / outdoor / medical

- 儿童：小零件防误吞、低压、无锐边、成人监护、年龄标识；教育套件写教师提示；
- 户外：IP54 起步、排水孔、防凝露、抗 UV；雨天/涉水单独评估；失联自动停机/上浮/回收；
- 医疗：只做工程原型，不做诊断/治疗声明；涉及康复/接触人体必须持证评估。

## 7. 许可与开源

| 类型 | 可用 | 注意 |
|---|---|---|
| 代码 | MIT、Apache-2.0、BSD | Apache 需保留 NOTICE；MIT 保留版权声明 |
| 代码（传染） | GPL-2.0/3.0、AGPL | 分发/网络服务可能要求开源；商业项目先评估 |
| 硬件 | CERN-OHL-S/W/P、MIT | CERN-OHL-S 有传染性；衍生设计要同许可 |
| 文档 | CC-BY-4.0、CC-BY-SA | 署名；SA 要求相同方式共享 |
| 模型/权重 | Apache/MIT/CC-BY | **禁用非商用/研究仅用/无许可权重** |
| 字体/图标 | OFL、CC0 | 检查嵌入授权 |

规则：每个外部依赖写进 `decisions` 的 `external:<name>`，锁版本，附许可证；GPL/AGPL 不得静默混入闭源交付；不引入来源不明的模型权重。

## 8. 供应链

- 型号必须真实可买：写厂商 + 完整型号 + 采购关键词 + 替代料；
- 价格是快照，写 `quote_date`；采购前复核；
- 停产/EOL 件（CST-09）必须换在产替代；交期 >30 天与档位不匹配要预警；
- 警惕翻新/假货：优先授权分销/官方店；电池、电源、舵机是重灾区；
- 关键件准备替代料（pin-to-pin 或同规格），写进 docs/01；
- 整机 BOM 与文档型号必须一致（CST-13 / S14）。

## 9. 无线与空域（如适用）

- 2.4G/5G 模块用认证模组，不改天线；SRRC/CE/FCC 按市场；
- 无人机：实名登记、120 m 限高、禁飞区、视距内、桨叶护罩、LiPo 防火袋；不自研飞控；
- 图传/遥控失联保护必须实测。
