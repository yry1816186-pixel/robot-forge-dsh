> 用途：用户说出形态后，**先查这里再报型号/价格/库**，避免幻觉。所有版本与星数为 2026-11-11 调研快照；真正落项目时以仓库 README/PyPI 为准，并在 `forge/research.md` 记录锁定版本。
> **按形态分节，但不是形态白名单**：没列出的形态按 §0 的三轴选型法从最近一节推导，不要因为查不到就拒绝或硬套。
> 配套：`archetypes.md`（12 类配方）、`blueprints.md`（内置模板与 freeform）、`spec.md`（交付契约）、`quality.md`（评审）。
> v2.0 增补：视觉云台、移动抓取、割草、水下四类高风险栈，以及工具链版本纪律（§15–§16）。

## 0. 三轴选型法

先问三个数，再选栈：

| 轴 | 取值 | 影响 |
|---|---|---|
| 算力 | 端侧 MCU / 单板机 / 主机+云 | 决定能不能跑视觉、LLM、SLAM |
| 预算 | <¥300 / ¥300–1000 / >¥1000 | 决定舵机、传感器、结构件档次 |
| 延迟 | >1s 可接受 / 300ms–1s / <300ms | 决定语音链路与推理位置 |

**默认原则：**
- 端侧只做实时控制与唤醒，重计算放主机/云；断网必须有降级行为；
- 先买「能跑的最小闭环」再升级，不要一次买齐旗舰件；
- 运动类必须做功率与力矩核算；移动类必须做失联/超时保护；
- 电池类必须做欠压/过流/过温保护与阻燃外壳；
- 任何「开源」交付都先查许可证，GPL/AGPL 与闭源商用冲突。

## 1. 桌面陪伴 / 语音交互

**默认栈（¥260–¥800）**

| 层 | 选择 | 说明 |
|---|---|---|
| 主控 | ESP32-S3（8MB Flash + 8MB PSRAM） | 端侧唤醒、音频、表情、舵机；不建议直接跑 LLM |
| 麦克风 | INMP441（I2S）或 ES7210（四麦阵列，带 AEC 更好） | 单麦便宜；远场/回声场景选阵列 |
| 功放 | MAX98357A（I2S 3W） | 免 DAC，接线少；喇叭 4Ω 3W |
| 显示 | GC9A01 1.28" 圆屏（SPI） | 表情成本低；文字多改 ST7789 2.0" |
| 运动 | MG90S ×2（云台） | 便宜、金属齿；堵转电流大，必须独立 5V 供电 |
| 感知 | VL53L0X（I2C，0x29）+ TTP223 触摸 | 在场/摸头反馈 |
| 供电 | 5V 3A 适配器；舵机与逻辑分轨 + ≥470µF 母线电容 | 舵机启动瞬间掉压会复位 MCU |

**上游参考（按需借用，不要整包贴）**
- `xiaozhi-esp32`（MIT，约 33k★）：ESP32-S3 语音助手固件，板型多；**许可证友好**，适合做端侧语音壳；版本/板型支持以其 README 为准，不要写死 IDF 版本。
- `xiaozhi-esp32-server` 类服务端：可做 ASR/LLM/TTS 编排，但部署复杂；零基础项目优先「主机 Python + 串口」而不是全套服务端。
- Pipecat 1.15.0 / LiveKit Agents 1.8.11：主机侧实时语音编排（VAD/打断/工具调用），适合 PC/树莓派方案。
- Silero VAD 6.2.3、faster-whisper 1.2.1、Kokoro 0.9.4、sherpa-onnx 2.0.1：本地 VAD/ASR/TTS 组合。
- **Piper 已迁至 `piper1-gpl`，GPL-3.0**：闭源/商用项目禁用；开源项目可用但要同许可。

**延迟预算（端到端，目标 <1.5s）**
```text
唤醒 100–300ms + VAD 200ms + ASR 200–500ms + LLM 首 token 300–800ms
+ TTS 首包 150–400ms + 播放缓冲 100ms ≈ 1.0–2.0s
```
要「像人」必须做：流式 ASR/TTS、barge-in（打断）、AEC（或耳机/近场）、固定短回复。整句合成再播放必然 >2s。

**坑**
- 没有 AEC 就做「随时打断」→ 机器人听见自己；先做按键/唤醒词轮次。
- 麦克风与功放共用 3.3V 且走线差 → 底噪/啸叫；模拟地与数字地分开，功放电源加 LC。
- 用 GPIO 直接驱动舵机 → 电流不足/复位；舵机电源独立，信号共地。
- 把 API key 写进固件 → 泄露；密钥只放主机/服务端。
- 全程联网 ASR/TTS → 断网变砖；至少保留 5 句本地应答 + 表情反馈。

**验证配方**
1. `pytest` 跑协议/人格/隐私测试（mock 串口）；
2. 舵机运动包络脚本检查角度与干涉；
3. 功耗脚本检查 5V/3.3V 峰值余量；
4. 实物：1.5m 叫名字 10 次、断网 5 句、连续 2h 温升。

## 2. 桌面机械臂 / 抓取

**默认栈（¥700–¥3000）**

| 方案 | 成本 | 说明 |
|---|---|---|
| LeRobot SO-101（推荐入门） | 单臂约 $122 / ¥682（不含主控与电源） | 6×STS3215 总线舵机，3D 打印结构，LeRobot 官方支持 follower/leader |
| SO-ARM100 | 与 SO-101 同源 | 老版本；优先 SO-101 |
| 总线舵机 | STS3215（约 ¥98/个） | 位置/温度/负载回读，串联总线，省线 |
| 主控 | PC（训练/推理）+ USB 串口；或树莓派 | LeRobot 0.7.0 需 Python≥3.12 |
| 相机 | USB 摄像头 ×1–2 | 手眼标定；分辨率与帧率够用即可 |

**软件栈**
- LeRobot 0.7.0（Apache-2.0，约 28.8k★）：`lerobot-record/train/eval/rollout`，数据集 v3 = Parquet + MP4；SO-101 用 `so101_follower` / `so101_leader`。
- 模仿学习：ACT / Diffusion Policy；数据 20–50 条演示起步；先跑通「抓方块放盒子」。
- 远程推理：openpi（π0/π0.5）可做 websocket policy server，机器人端只跑 client；显存：推理 >8GB、LoRA >22.5GB、全量 >70GB。
- 仿真：MuJoCo 4.0（2026-11 拆包，升级需 `pip uninstall mujoco` 再装）；Isaac Sim/Lab 是专有许可，不能算「开源交付」。

**坑**
- 6 个舵机同时启动 → 5V/12V 掉压；分组上电、软启动、母线电容。
- JST-XH 端子约 3A，带不动 6 舵机峰值；用 XT30/螺丝端子，20AWG 约 5A。
- 不做标定就训练 → 数据全废；先做零位/方向/限位标定并写进 `docs/05`。
- 夹爪无限位/无力反馈 → 夹坏物体或堵转烧舵机；加电流/温度保护。
- LeRobot 版本迭代快 → 锁 commit/tag；把版本写进 `docs/04` 与 `decisions.md`。

**验证配方**
1. 零位/方向/限位脚本（不接硬件也能 mock）；
2. 单关节阶跃响应 + 重复定位精度（手动记录）；
3. 抓取成功率 20 次 ≥80%（manual，附视频）；
4. 堵转 5s 保护（manual）。

## 3. 差速小车 / 移动底盘

**默认栈（¥300–¥1200）**

| 层 | 选择 | 说明 |
|---|---|---|
| 主控 | ESP32-S3 / ESP32-C3 | 实时控制、Wi-Fi 遥测；视觉另加模块 |
| 驱动 | TB6612FNG（2×1.2A）或 DRV8833 | 别用 L298N（压降大、发热） |
| 电机 | N20 减速电机 + 编码器（或 TT 马达入门） | 闭环必需编码器 |
| 测距 | VL53L0X ×1–3 或 HC-SR04 | 避障；ToF 受阳光影响 |
| 姿态 | MPU6050 / ICM-42688 | 航向辅助；漂移需磁力计或视觉 |
| 供电 | 18650 2S（7.4V）+ 降压 5V/3.3V；或 12V 适配器 | 电机与逻辑分轨；电池加保护板 |
| 结构 | 3D 打印底盘 + 万向轮 | 离地间隙、轮距、重心 |

**软件**
- 端侧：速度环 PID + 编码器中断 + 超时停车 + 低电压保护；
- 主机：Python 遥测/遥控/录数据；ROS 2 可选（jazzy/kilted/lyrical 均 active，别硬编码 distro；micro-ROS 组件要求 IDF≥5.4）。
- 导航：室内小场景不必上 Nav2；先做「直线 + 转向 + 避障」状态机。要 SLAM 再上 ROS 2 + slam_toolbox/Nav2 1.5.0。

**坑**
- 只做开环 PWM → 电池压降后走不直；必须编码器闭环。
- 电机电源与 MCU 共地不良 → 复位/乱跑；星形接地、电机端加 100nF。
- 轮子打滑 → 里程计失真；低速标定、地面一致。
- 没有急停/失联保护 → 撞墙；看门狗 + 遥控失联 0.5s 停车 + 物理开关。
- 电池过放 → 鼓包；保护板 + 欠压阈值 + 蜂鸣提示。

**验证配方**
1. 1m 直线偏差 <5cm（manual/视频）；
2. 原地转 90° 偏差 <5°；
3. 避障 10 次不撞；
4. 失联 0.5s 停车；
5. 续航实测（记录电压曲线）。

## 4. 四足 / 人形（高风险）

**结论：零基础默认不自研整机；要做必须先过预算、场地与安全门槛。** 成本、调试难度、安全风险都远超预期。

- K-Scale Labs 2025-11 解散：K-Bot 定价 $16,000、只做 10 台、成本 >$100k、退款 → **不要引用为可复制方案**。
- Open Duck Mini（约 4.7k★）无正式 release，复现依赖特定 commit/打印件 → 只能作研究参考，不能承诺「照做能走」。
- Unitree Go2 约 ¥9,997 起：买成品比自研便宜且安全。
- 若用户要做：先定义阶段性验收（2 自由度云台 / 6 自由度单臂 → 整机）；预算 ≥¥2 万、6 个月、有调试场地，并签安全须知。不承诺超出预算与经验的整机。

## 5. 无人机 / 飞控

**结论：不自研飞控。** 用成熟固件 + 合规机体。

- 固件：Betaflight（竞速/穿越）、ArduPilot / PX4（自主飞行）；都是成熟开源栈，二次开发只做配置与上层。
- 法规：中国境内需实名登记、限高 120m、禁飞区；室内飞行风险高；桨叶必须护罩。
- 电池：LiPo 4.2V/cell 满电、3.5V/cell 存储；鼓包立即停用；充电必须有人看守。
- 定位：室内无 GPS 需光流/视觉；不要承诺「室内自主避障」除非有实测。
- 验证：地面站日志、失控保护、低电量返航；第一次飞在空旷场地 + 护罩。

## 6. 传感节点 / 智能家居 / 浇花

**默认栈（¥80–¥300）**
- 主控：ESP32-C3（便宜、Wi-Fi）或 ESP8266（更便宜但引脚少）；
- 传感：BME280（温湿压）、 capacitive 土壤湿度、BH1750（光照）、PIR（人体）；
- 执行：5V 继电器/ mosfet 驱动水泵；**市电负载必须用成品智能插座，不要 DIY 220V**；
- 软件：ESPHome（YAML，免编程）或 Arduino + MQTT/Home Assistant；深睡眠降功耗；
- 供电：USB 5V 或 18650 + 保护板；水泵启动电流大，电源留 2 倍余量；
- 坑：土壤探头电解腐蚀（间歇供电）、水泵干烧、Wi-Fi 重连、OTA 变砖（双分区）、传感器校准。

**验证配方**：7 天数据记录、断网重连、缺水保护、OTA 回滚。

## 7. 教育 / 积木 / MicroPython

- micro:bit / ESP32 + MicroPython：降低门槛，适合 8–14 岁；
- 结构用积木/纸板，避免 3D 打印门槛；
- 图形化：MakeCode；代码版给 Thonny；
- 安全：无市电、无锂电池（用 AA 电池盒）、无小零件误吞；
- 文档要多图、少术语，每步一张「应该看到什么」。

## 8. 视觉 / AI 能力放置

| 需求 | 方案 | 成本/限制 |
|---|---|---|
| 人脸检测/跟随 | ESP32-S3 + 摄像头（低帧率）或 K210 | 分辨率/帧率有限，别承诺识别身份 |
| 物体识别 | 树莓派 4/5 + YOLO 轻量模型 | 需散热、5V 3A+ |
| 大模型对话 | 主机/云 API；端侧只做音频流 | 延迟与费用；密钥不进固件 |
| 本地 LLM | 8GB 显存跑 7B Q4；更大需 16–24GB | 推理慢，先做异步回复 |
| 抓取策略 | LeRobot + ACT/DP；openpi 远程 | 数据采集成本高 |

**隐私默认**：摄像头/麦克风必须有物理断电或明确指示灯；默认不上传原始音视频；隐私政策写进 docs/07；本地处理优先。

## 9. 电源与驱动核算（写进 `power` 与 `docs/03`）

```text
舵机峰值电流 ≈ 堵转电流（MG90S 约 700mA@5V，MG996R 约 2.5A@5V，STS3215 约 1.5A@12V）
电源额定 ≥ 峰值合计 × 1.3
母线电容 ≥ 470µF（每 2–3 个舵机再加 220µF）
线径：20AWG≈5A，22AWG≈3A，24AWG≈2A，26AWG≈1A（短距离）
电池续航 ≈ 容量Wh × 0.85 / 平均功率W
电池放电 ≥ 峰值电流 / 容量Ah（C-rate）
逻辑轨与动力轨分开；共地单点；舵机信号串 100–330Ω
```

**上电顺序**：逻辑先上、动力后上；断电相反。**首次上电**：限流电源 + 舵机慢速回中 + 限位自检，不要直接跑动作组。

| text-to-CAD 生成件直接生产 | 模型多为非商用；只能做灵感，生产用参数化脚本 |

## 15. v2 补齐：四类高风险/高阶栈

### 15.1 视觉云台（camera-gimbal）

| 层 | 默认选择 | 备注 |
|---|---|---|
| 主控 | ESP32-S3（带 PSRAM）或树莓派 Zero 2 W | 端侧只做采集/推流，识别放主机 |
| 相机 | OV2640/OV5640（DVP）或 USB UVC | 分辨率与帧率先定，再选接口 |
| 云台 | 2 轴 MG90S/SG90 或总线舵机 | 扭矩按相机+支架偏心算，留 2× |
| 跟踪 | 主机 OpenCV / MediaPipe，PID 输出角度 | 端侧不做重推理 |
| 隐私 | 物理挡片、采集指示灯、默认不上传 | 必须写 `security.data` |

验收：① 30 fps 采集不丢帧；② 目标移动时云台跟随延迟 <300 ms；③ 断网进入固定姿势；④ 遮挡摄像头有提示。坑：DVP 排线过长花屏；舵机抖动需独立供电+滤波；逆光过曝。

### 15.2 移动抓取（differential-drive-mobile-manipulator）

| 层 | 默认选择 | 备注 |
|---|---|---|
| 底盘 | wheel-rover 差速底盘 | 先验证移动，再加臂 |
| 机械臂 | 3–4 自由度 + 夹爪（总线舵机） | 负载/臂展决定舵机，别用 MG90S 硬撑 |
| 算力 | 主机（Jetson/迷你 PC 可选） | 抓取规划/视觉放主机 |
| 电源 | 底盘 2S/3S + 臂独立 6–7.4 V | 臂启动瞬间不要拉垮主控 |
| 安全 | 急停、限位、夹持力限制、断电泄力 | 夹伤风险最高 |

验收：① 空载/满载都能到指定点；② 夹取 200 g 不掉；③ 移动中臂不晃到失控；④ 急停 0.5 s 内断电。坑：重心前移翻车；臂展与负载非线性；总线舵机 ID/波特率配错。

### 15.3 割草/户外（lawn-mower）——高风险

| 层 | 默认选择 | 备注 |
|---|---|---|
| 定位 | RTK GPS 或边界线 | 无定位不做“自主” |
| 感知 | 超声波/碰撞条/抬起检测 | 刀片区域必须双冗余 |
| 刀片 | 成品切割盘 + 护罩 + 离手停机 | 零基础不建议自研刀片 |
| 防护 | IP54+、防水接头、倾角断电 | 雨天禁用的写清楚 |
| 法规 | 实名/保险/噪声/物业许可 | 按当地要求，不承诺“全自动” |

验收：① 抬起/翻转 0.2 s 内停刀；② 碰撞条触发停机；③ 边界外不越界；④ 雨天/积水禁止启动。**发布门槛高于普通项目**：安全相关 must 不允许 Beta。

### 15.4 水下/船（underwater）——高风险

| 层 | 默认选择 | 备注 |
|---|---|---|
| 密封 | O 圈 + 亚克力/铝筒 + 压力测试 | 先做 1 m 静水测试 |
| 推进 | 双向 ESC + 无刷/有刷推进器 | 留 30% 推力余量 |
| 浮力 | 配重使微正浮力 | 失联自动上浮/断电上浮 |
| 通信 | 系绳优先；无线仅浅水 | 水下无线衰减严重 |
| 安全 | 漏水检测、失联上浮、螺旋桨护罩 | 远离人/宠物/水草 |

验收：① 1 m 水深 30 min 无渗漏；② 失联 5 s 内停桨/上浮；③ 低电量返航/上浮；④ 推进器护罩牢固。坑：O 圈压缩量、凝露、线缆进水、压差导致壳体变形。

## 16. 工具链版本纪律

- 所有依赖写**锁定版本**（`==`/`commit`/`board`），不写“最新”；
- 安装前在 `forge/research.md` 记：日期、版本、来源链接、许可；
- Python 3.11/3.12 为基线；Node 22/24；PlatformIO 锁 board/platform 版本；
- 升级先跑 `check`/`verify`，通过再改 lock；升级失败可回滚；
- 不用来源不明的模型权重/二进制；不用非商用权重做“开源可商用”；
- CI 与本地同版本，避免“我这能跑”。

| 工具 | 用途 | 缺失时 |
|---|---|---|
| Python 3.11+ / pytest | 主机软件与测试 | required 命令 FAIL，装或标未验证 |
| PlatformIO | 固件编译/单测 | firmware-tests 标 optional + needs |
| build123d | 参数化 CAD | cad-build optional；文档给安装 |
| MuJoCo | 仿真 | sim 改纯 Python 运动学 |
| Node 22+ | 宿主插件/评测 | 开发期必需，用户项目不依赖 |
| kicad-cli/openscad/ffmpeg | 原理图/模型/视频 | 对应 optional |
