# 仿真与静态核算

这个目录不做三维仿真，只做两件零基础也能跑的事：把 `forge/robot.yaml` 里的运动与功率数字算一遍，证明它们没有互相矛盾。命令都只依赖 Python 标准库。

## 1. 运动学校核

```bash
python sim/check_kinematics.py
```

它会算：

- 最高车速对应的轮子转速，是否超过 TT 电机额定转速；
- 最大转向角速度需要的左右轮速差；
- 最高速下的最小转弯半径；
- 从看到障碍到停下的距离（串口延迟 + 主循环 + 超声周期 + 刹车距离），是否小于 300 mm 阈值并留出 50 mm 余量。

失败时退出码为 1，并在 `FAIL` 行写明是哪个数字越界。改 `robot.yaml` 的 `motion` 段或 `mechanical.limits` 后重跑。

## 2. 功率、续航与成本

```bash
python sim/check_power.py
```

它会算：

- 每条电源轨的典型与峰值电流，峰值不得超过降压模块标称；
- 2S 电池的估算续航（`mah × cells × 3.7 V × 0.85 ÷ 典型功率`），不得低于需求里的 0.5 h；
- 物料加运费是否超过 `cost.target_cny`。

## 3. 这些检查不能证明什么

- 不能代替上车实测：打滑、地面材质、超声盲区、电池老化都测不出来；
- 不能证明固件真的按这些数字执行，固件测试在 `firmware/test`；
- 不能证明接线正确，接线看 `docs/03-接线表.md`。

真实的避障距离和续航要按 `docs/09-验证报告.md` 记录为 `manual` 证据，不能拿这两个脚本冒充实机结果。
