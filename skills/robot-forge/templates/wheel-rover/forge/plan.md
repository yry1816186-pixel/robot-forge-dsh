# 建造计划

> 目标：两个周末做出一台能遥控、能自动停车、有状态显示的差速小车。
> 每一格都对应一个可检查的产物，不是日程表。完成一项就在前面打 `x`。

## 阶段与产物

| 阶段 | 产物 | 完成判据 | 预计 |
|---|---|---|---|
| P0 选题确认 | 一页方案、预算表 | 用户确认「遥控 + 自动停车」是核心，其他都可砍 | 0.5 h |
| P1 采购 | 下单清单（docs/01） | 16 项全部有链接、有替代料；电池是带保护板成品 | 1 h |
| P2 到货检查 | 检查记录（docs/02） | 万用表测电池电压、逐件外观检查 | 0.5 h |
| P3 机械与电气装配 | 接线完成的车（docs/02、03） | 三个检查点全过；架空上电轮子能转 | 3 h |
| P4 固件 | 能接受串口命令的固件（docs/04） | `pio run` 通过；串口 PING 有回复；轮子方向正确 | 3 h |
| P5 主机软件 | robotd 遥控（docs/05） | `pytest` 全绿；`--mock` 能跑脚本；真机能遥控 | 3 h |
| P6 联调与安全 | 避障、低电、堵转保护 | REQ-004 手工验证通过；掉线 0.5 秒内停车 | 2 h |
| P7 验证与交付 | 验证报告（docs/09） | verify 全绿；证据登记；文档与实物一致 | 1.5 h |

## 关键路径

```text
采购 → 到货检查 → 电气装配 → 固件烧录 → 主机联调 → 安全测试 → 验证
```

机械装配与主机软件可以并行：主机软件用 `--mock` 不需要车。

## 里程碑

- **M1 架空能转**：P3 完成，两个轮子方向正确、PWM 可控。此时不要落地。
- **M2 能遥控**：P5 完成，键盘能控制前进后退转弯，松手停。
- **M3 能交付**：P7 完成，verify 全绿，docs/09 有每条 must 需求的证据。

## 明确不做

- 不做 PID 速度闭环（没有编码器）
- 不做 SLAM、不做摄像头
- 不做 Wi-Fi/手机 App
- 不做自制结构件与 3D 打印

## 风险与应对

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 电池/降压模块接错 | 上电冒烟、电压异常 | 立即断电；按 docs/08 逐段排查；不要带电插拔 |
| 轮子方向反 | 前进时原地转 | 交换该电机两根线，或改固件方向常量 |
| 超声一直读到 0 | OLED 显示 0 mm | 检查 Trig/Echo 与分压；先单独测模块 |
| 主机找不到串口 | `--port` 报错 | 装 CH340/CP210x 驱动；用 `--list` 看设备 |
