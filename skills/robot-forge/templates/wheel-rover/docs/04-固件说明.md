# 固件说明

## 环境

- [PlatformIO](https://platformio.org/)（VS Code 插件或命令行 `pio`）
- 开发板：ESP32-S3（Arduino framework）
- USB 驱动：板载 USB 原生，一般免驱；若设备管理器出现未知设备，装 CH340 或 CP210x 驱动（视开发板）

验证安装：

```bash
pio --version
cd firmware
pio run -e esp32-s3
```

首次编译会下载 Arduino-ESP32 平台与库，约 5-10 分钟，需要网络。

## 烧录

```bash
cd firmware
pio run -e esp32-s3 -t upload
pio device monitor -b 115200
```

- 烧录时只插 USB，不要接电池。
- 若提示无法进入下载模式：按住 BOOT，点一下 RST，再松开 BOOT，重新烧录。
- 烧录后串口应打印启动信息；发送 `PING` 应回 `OK`。

## 代码结构

```text
firmware/
├── platformio.ini        # 两个环境：esp32-s3（真机）与 native（单测）
├── include/config.h      # 引脚、阈值、心跳超时
├── lib/rover_core/       # 纯 C++，不依赖 Arduino，可在电脑上单测
│   ├── protocol.h/.cpp   # 文本协议解析与遥测格式化
│   └── drive.h/.cpp      # 差速混控与限幅
├── src/
│   ├── main.cpp          # 初始化、主循环、安全规则
│   └── sensors.h/.cpp    # 超声、IMU、电池电压、OLED
└── test/test_core.cpp    # Unity 单测（native 环境）
```

设计原则：**能单测的逻辑不放进 `main.cpp`**。协议解析与差速混控都在 `lib/rover_core`，不引用 `Arduino.h`。

## 串口协议

主机 → 固件（一行一条，`\n` 结尾，最长 48 字节）：

| 命令 | 含义 | 示例 |
|---|---|---|
| `V <lin_mm_s> <ang_mrad_s>` | 设定线速度（mm/s）与角速度（mrad/s） | `V 200 0` |
| `S` | 立即停车 | `S` |
| `PING` | 心跳/探活 | `PING` |

固件 → 主机：

| 回包 | 含义 | 示例 |
|---|---|---|
| `OK` | 命令已接受 | `OK` |
| `ERR <code>` | 非法命令或参数越界 | `ERR 2` |
| `T <enc_l> <enc_r> <dist_mm> <yaw_mdeg> <batt_mv>` | 50 Hz 遥测 | `T 0 0 412 15 7810` |

错误码：1=行太长，2=命令不认识，3=参数个数不对，4=参数不是数字，5=超速。

约束：

- 线速度绝对值不超过 400 mm/s，角速度绝对值不超过 1200 mrad/s。
- 500 ms 内没收到任何合法命令，固件自动停车。
- 超声连续 3 次小于 300 mm，固件强制停车并回报 `ERR 6`（下一帧遥测里体现）。

## 单元测试

```bash
cd firmware
pio test -e native
```

不需要开发板。测试覆盖：合法/非法命令、超长行、限幅、左右轮符号、零速。

## 与 robot.yaml 的关系

`firmware/include/config.h` 的引脚必须与 `forge/robot.yaml` 的 `buses`/`pins` 一致；`python tools/forge.py check` 会检查文档与 YAML，但**不检查 C++ 引脚常量**，所以改引脚时必须同时改两处，并在 `docs/03` 的检查表里打勾。

## 升级

改完固件：

1. `pio run -e esp32-s3 -t upload`
2. 架空重测方向与急停（检查点 5）
3. 落地测避障（检查点 6）
4. 把结果登记到 `docs/09`
