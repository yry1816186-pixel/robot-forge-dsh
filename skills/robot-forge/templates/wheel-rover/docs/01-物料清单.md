## 采购提示

1. **电池只买成品组**：带保护板、带插头（XH2.54 或 XT30），不要买裸 18650 自己焊。价格低于 ¥25 的 2S 组通常没有真实保护板。
2. **底盘看孔位**：2WD 亚克力套件要能放下 65 mm 轮，且电机支架与底盘孔位匹配；买前问清是否含万向轮。
3. **TB6612 要带散热片**：不带也能用，但堵转测试时会更热；优先买带铝片的版本。
4. **HC-SR04 买 5V 版**：市面上有 3.3V 版本，Echo 电平不同，接线表按 5V 版写。
5. **OLED 买 4 针 I2C**：7 针 SPI 版接线更多，不适用本项目的引脚表。
6. **降压模块买可调版**：MP1584EN 与 LM2596S 都要能调到 6.0V/5.0V；下单前确认带电位器。
7. **一次买齐耗材**：杜邦线、22AWG 红黑线、热缩管、扎带、双面胶，单独补运费不划算。

## 替代料

| 原件 | 可替代 | 注意 |
|---|---|---|
| 微雪 ESP32-S3-DEV-KIT-N8R8 | 其他 ESP32-S3 开发板（带 USB-C、8MB Flash） | 引脚编号可能不同，必须重查 `docs/03` |
| TB6612FNG | DRV8833 | 持续电流更小，堵转测试要缩短 |
| HC-SR04 | US-100（串口/电平两种模式） | 接线与固件都要改，不作为首选 |
| MPU6050 | MPU6500 / ICM-20602 | 寄存器不同，需改驱动 |
| SSD1306 0.96 | SSD1306 0.91 | 分辨率不同，界面要调 |
| 2S 成品电池组 | 2S 18650 + 独立保护板 + 电池盒 | 必须确认保护板 20A 以上 |

## 不要买错

- **不要买 L298N**：压降大，6V 供电到电机只剩约 4V，速度慢且发热。
- **不要买 3.7V 单节电池 + 升压**：电机峰值电流会把升压模块打保护。
- **不要买没有保护板的 18650**：过放、短路都可能起火。
- **不要买 5V 充电宝当主电源**：电机启动瞬间掉压，主控会复位。
- **不要用杜邦线给电机供电**：线径不够，压降与发热都超标。

## 到货检查

逐件检查并在 `docs/09` 记录：

1. 电池组：万用表测总电压，2S 满电约 8.4V，低于 7.0V 先充电；闻是否有异味、看是否鼓包。
2. 降压模块：空载接电池，调电位器到 6.0V 与 5.0V，误差 ±0.2V；调好后电位器打胶。
3. TB6612：目视焊点，VCC 与 VM 不要接反；用万用表测 VM-GND 不短路。
4. 超声：单独给 5V，Trig 给 10us 脉冲，Echo 应有高电平；没有示波器就用主控读。
5. 电机：两节 1.5V 电池点一下，确认能转、轴不歪。
