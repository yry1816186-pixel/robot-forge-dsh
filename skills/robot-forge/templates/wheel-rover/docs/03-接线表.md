## 电源树

```text
2S 电池 7.4V（满 8.4V，截止 6.2V）
  └─ 10A 保险丝 → 船型开关
       ├─ MP1584EN → 6.0V ──→ TB6612 VM ──→ 左/右 TT 电机
       │                    └─ 470uF 电容（靠近 VM）
       └─ 5V 3A 模块 → 5.0V ──→ ESP32 5V 引脚
                            ├─ HC-SR04 VCC
                            └─ OLED VCC（模块自带 3.3V 稳压时接 3.3V 更稳）
```

注意：

- **不要用 ESP32 开发板的 5V 引脚反供**其他大电流设备；5V 模块直接给开发板 5V 脚。
- 所有 GND 必须共地，包括电池、两颗降压、主控、驱动、传感器。
- I2C 的 SDA/SCL 不要接 5V；MPU6050 与 OLED 都是 3.3V 逻辑。

## 上电顺序

1. 断电，接好所有信号线。
2. 空载调好 6V 与 5V（见 `docs/02` 检查点 2）。
3. 只插 USB，确认串口与固件启动正常。
4. 接电池，开开关；观察是否有异味、发热、屏幕是否亮。
5. 架空测试轮子方向。
6. 落地低速测试。

任何一步异常：立即关开关、拔电池，按 [故障排查](08-故障排查.md) 逐段测，不要带电插拔。

## 接线检查表

- [ ] 电池极性正确，插头有防呆标记
- [ ] 保险丝与开关串在正极
- [ ] 6V 与 5V 输出用万用表确认过
- [ ] TB6612 的 VM=6V、VCC=3.3V、GND 共地
- [ ] 超声 Echo 经 1k/2k 分压
- [ ] 电池检测分压比约 4:1，ADC 输入不超过 3.3V
- [ ] I2C 两根线没有接反，模块地址不冲突
- [ ] 电机线与信号线分开走
- [ ] 所有接头有热缩或胶带，不裸铜

## 改引脚

改引脚只改 `forge/robot.yaml` 的 `buses` 与 `pins`，然后：

```bash
python tools/forge.py render
python tools/forge.py check
```

固件里的引脚在 `firmware/include/config.h`，必须与 YAML 同步改；只改一边会导致「文档对、实物不对」。改完重新烧录并做检查点 5。
