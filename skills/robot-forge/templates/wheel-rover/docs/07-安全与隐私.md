# 安全与隐私

## 安全

### 电池

- 只使用带保护板的成品 2S 18650 电池组；不要用裸电芯、不要自己点焊。
- 正负极插头做防呆标记；上电前用万用表确认极性。
- 电池鼓包、破皮、发热、闻到甜味：立即断电，移到室外空旷处，不要再充。
- 不要短路电池；不要把电池和钥匙、螺丝刀放同一个口袋。
- 充电必须有人看管，使用匹配的 2S 平衡充；不要用 5V 手机充电器直接充电池组。
- 长期存放电压约 7.6V（每节 3.8V），每 3 个月补电。

### 运动与堵转

- 第一次上电必须架空；确认方向正确再落地。
- 轮子卡住时电机会堵转，电流大、发热快；固件会在约 2 秒后停机，但不要依赖它，听到异响立即断电。
- 不要用手去拽转动的轮子；长发、围巾、鞋带远离轮轴。
- 车没有防跌落传感器，不要放在桌沿、楼梯口。

### 充电与市电

- 平衡充接 220V 市电，插头要接地；不要在潮湿地面充电。
- 充电器不要放在床上、纸上；充满拔掉。
- 雷雨天不要充电。

### 电气

- 所有接线在断电状态下完成；不要带电插拔电机线。
- 超声 Echo 是 5V，必须分压后再进 3.3V GPIO。
- 降压模块先空载调压再接负载；电位器调好后打胶固定。
- 主控、驱动、传感器必须共地；地线虚接会导致随机复位。

## 隐私

- 本车**没有麦克风、没有摄像头、没有 Wi-Fi**，不会采集或上传任何数据。
- 遥控只走 USB 串口，数据留在本机。
- 如果以后加摄像头或联网模块，必须同时更新本节与 `docs/09` 的证据，不能默默开启。
- 不要在孩子或客人不知情时用带摄像头的改装版拍摄。

## 出问题时

1. 立即关船型开关、拔电池。
2. 冒烟或起火：用干粉灭火器或厚衣物隔绝空气，不要用水浇锂电池。
3. 人员受伤先处理伤口并就医；保留现场照片，便于复盘。
4. 记录到 `docs/09`，写清时间、现象、处理方式。
