# 使用手册

## 首次使用

### 1. 充电

- 用 2S 平衡充给电池组充电，充电电流不超过 1A。
- 充电时人不要离开，电池放在瓷砖或金属盘上，远离纸、布、床。
- 充电器变绿灯后 30 分钟内拔掉，不要长期浮充。

### 2. 开机

1. 先插 USB（给主控供电，也用于遥控）。
2. 打开船型开关，电池接入。
3. OLED 应显示电压与距离；若黑屏，先看 [故障排查](08-故障排查.md)。
4. 电脑上运行 `python -m robotd.main --port COM5`。

### 3. 第一次遥控

1. 把车放在 2 米 × 2 米空地，周围不要有脚和电线。
2. 按 `w` 轻点一下，确认车向前动一点就松手。
3. 按空格，确认立即停。
4. 再试 `a`/`d`，确认左右转方向正确。
5. 用纸板在车前 30 cm 挡一下，确认自动停车。

## 日常

### 遥控行驶

- 起步用低速（`V 100 0` 左右），别一上来满速。
- 转弯时降低线速度，避免外侧轮打滑。
- 不要在人脚边、桌沿、楼梯口行驶；本车没有防跌落。
- USB 线不要绷直，留一点余量。

### 看状态

- OLED 第一行：电池电压（满 8.4V，低于 6.6V 应充电）。
- 第二行：前方距离（mm）；显示 `---` 表示超量程或没读数。
- 第三行：模式（IDLE/TELEOP/STOP）。

### 停车与收纳

- 先按空格或 `q` 退出，再关船型开关，最后拔 USB。
- 长期不用：把电池充到约 7.6V 存放，不要满电或空电久放；每 3 个月补一次电。
- 不要让车在阳光直射下暴晒；亚克力会变形，电池怕热。

## 维护

### 每次使用后

- 检查轮子是否缠头发、线是否磨破。
- 摸一下驱动与电机：温热正常，烫手要查堵转或降压。
- 擦掉底盘上的灰；超声探头用干布擦，不要用酒精。

### 每月

- 万用表测电池组电压与每节电芯电压，压差超过 0.1V 要做平衡充。
- 检查螺丝是否松动，尤其是电机支架与铜柱。
- 检查电源线绝缘，破皮立即换线。

### 每半年

- 给轮轴滴一小滴润滑油（不要滴到轮胎上）。
- 检查开关与插头是否氧化；氧化会增加接触电阻，导致掉压。
- 重新跑一次 `python tools/forge.py check` 与 `verify`，确认文档与代码没被改乱。

## 存放与运输

- 取出电池单独存放，不要和金属工具混放。
- 运输时用盒子固定，避免压到超声探头与轮轴。
- 不要托运已安装的锂电池；按当地运输规定处理。
