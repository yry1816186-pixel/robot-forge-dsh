# 软件说明

## 安装

主机需要 Python 3.10 或更新版本。

```bash
cd software
python -m pip install -e .
# 只跑测试的话，装 pytest 即可：
python -m pip install pytest
```

真机遥控还需要串口库（已写进 `pyproject.toml`）：

```bash
python -m pip install pyserial
```

## 运行

### 模拟模式（无硬件）

```bash
cd software
python -m robotd.main --mock --script "forward,left,stop"
```

输出会打印每条命令与模拟遥测，适合先确认逻辑，再接真车。

### 真机模式

```bash
# Windows 示例；串口号以设备管理器为准
python -m robotd.main --port COM5

# Linux
python -m robotd.main --port /dev/ttyACM0
```

键盘：

| 键 | 动作 |
|---|---|
| `w` / `↑` | 前进 |
| `s` / `↓` | 后退 |
| `a` / `←` | 左转 |
| `d` / `→` | 右转 |
| 空格 | 立即停车 |
| `q` | 退出（会先发停车） |

松手即停：每次按键只发一帧速度，松开后 150 ms 内发 `S`。

### 只发一条命令

```bash
python -m robotd.main --port COM5 --once "V 150 0"
```

## 配置

`software/robotd/config.py` 里的常量：

| 配置 | 默认 | 说明 |
|---|---|---|
| `MAX_LINEAR_MM_S` | 400 | 与固件限幅一致 |
| `MAX_ANGULAR_MRAD_S` | 1200 | 与固件限幅一致 |
| `HEARTBEAT_MS` | 200 | 主机心跳周期 |
| `RELEASE_STOP_MS` | 150 | 松键后多久发停车 |
| `BAUD` | 115200 | 串口波特率 |

命令行参数优先于配置；配置改完不需要重新安装。

## 模拟与真机的边界

- 模拟链路 `MockLink` 会按协议回 `OK` 与 `T`，但**不会模拟物理**：它不知道车会不会撞。
- 模拟模式不验证电机方向、超声分压、电池电压；这些必须真机做（`docs/02` 检查点 5/6）。
- 端到端测试用模拟链路，只能证明「协议与状态机正确」，不能证明「车能跑」。

## 接大模型（可选）

本版本不依赖任何大模型。若想让语音或视觉控制小车，建议在主机侧加一个「意图 → 速度命令」的适配层，并保留固件的本地避障与心跳超时；不要把安全规则交给模型。

## 卸载

```bash
python -m pip uninstall robotd
```

项目文件不受影响；删掉整个目录即可彻底清理。
