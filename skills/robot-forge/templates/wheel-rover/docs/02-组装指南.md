# 组装指南

## 工具

- 十字螺丝刀（PH0/PH1）
- 小号一字螺丝刀（调降压电位器，调好打胶固定）
- 万用表（必须；测电压、通断、极性）
- 剥线钳、斜口钳、电工胶带、热缩管
- 双面胶、扎带（固定电池与走线）

不需要 3D 打印机、不需要焊台；只有给电源线头上锡时才需要电烙铁（可选）。

结构使用成品 2WD 亚克力底盘套件：底板、两层亚克力、两个 TT 电机与轮子、一个万向轮、电机支架与螺丝。不含自制打印件。

## 步骤

### 第 1 步：底盘与电机

1. 按套件说明把两个 TT 电机装到电机支架，再固定到底盘两侧；电机轴朝外。
2. 装轮子：先不要压到底，留 1 mm 间隙，避免摩擦侧板。
3. 万向轮装在前端（远离电机的一侧），高度与两轮齐平。
4. 用手推一下，确认三轮着地、不晃。

> 装反了会怎样：电机左右互换不影响行驶，但「左轮」在固件里对应的是同一侧，接线时按 `docs/03` 的标注走，不要凭感觉。

**检查点 1：底盘落地**

- 三轮同时着地，推车能直线滑行 30 cm 不偏向。
- 轮子转动不蹭侧板。
- 电机线从底盘孔穿出，长度够接到驱动板。

### 第 2 步：主控、驱动、降压模块布局

1. 用 M3 铜柱把 ESP32-S3、TB6612、两颗降压模块架空固定在底盘上。
2. 布局原则：电池在后、电机驱动靠近电机、主控与传感器远离电源线。
3. 降压模块的电位器朝向可调的一侧，方便空载调压。
4. 所有模块先用双面胶临时定位，确认走线后再上螺丝。

**检查点 2：空载调压（不接任何负载）**

- 电池经开关接到两颗降压模块输入，**输出端先不接任何东西**。
- 万用表测 6V 模块输出：调到 6.0V ±0.2V。
- 万用表测 5V 模块输出：调到 5.0V ±0.2V。
- 调好后给电位器点一点热熔胶或指甲油固定。
- 断电，等 10 秒，再确认输出没有电压（电容放电）。

### 第 3 步：电源与开关

1. 电池正极 → 10A 保险丝 → 船型开关 → 两颗降压模块输入正极。
2. 电池负极 → 两颗降压模块输入负极（共地）。
3. 电机电源从 6V 模块取，主控/超声/OLED 从 5V 模块取。
4. 所有电源线用 22AWG 红黑线，接头热缩；不要用杜邦线走电机电流。
5. 电机端并联 470uF 电解电容（注意正负极），靠近 TB6612 的 VM-GND。

**检查点 3：上电前的通断与极性**

- 断电状态下用万用表通断档：开关闭合时电池正极到 6V/5V 输入正极应导通；断开时应断开。
- 确认没有「正极到地」短路。
- 确认所有模块的 VCC/GND 没有接反。
- 确认电池插头做防呆标记（红点对红点）。

### 第 4 步：信号线

1. 按 [接线表](03-接线表.md) 接 TB6612、超声、I2C、电池分压。
2. 超声 Echo 必须经 1k/2k 分压；分压点接 GPIO12，GND 共地。
3. 电池正极经 100k/33k 分压接 GPIO1；分压比约 4.03，8.4V 对应约 2.08V。
4. 所有信号线远离电机线，交叉时尽量垂直。
5. 用扎带把线束固定在底盘上，避免轮子卷线。

**检查点 4：信号与地**

- 万用表测所有模块 GND 与电池负极相通。
- 测超声 Echo 分压点对地电压，接 5V 时应在 3.3V 以内。
- 测电池分压点电压，与电池总电压之比约 1:4。
- 主控 USB 插上电脑能识别串口（先不接电池）。

### 第 5 步：架空首测

1. 车架空，轮子悬空。
2. 先插 USB，确认串口能打开、固件启动日志正常。
3. 再接电池、开开关；手放在开关旁，异常立即断电。
4. 发送 `PING`，应回 `OK`；发送 `V 100 0`，两轮应同向慢转。
5. 发送 `S`，两轮立即停。

**检查点 5：方向与急停**

- 前进命令下两轮同向（从车尾看都向后转，车才会向前）。
- 左转命令下左轮慢、右轮快。
- `S` 与拔掉 USB 都能在 1 秒内停车。
- 电机与驱动不烫手（温热正常）。

### 第 6 步：落地与避障

1. 放到平整地面，先用低速（`V 80 0`）走 1 米。
2. 用纸板在车前 30 cm 处挡一下，确认自动停车。
3. 移开纸板，发送 `S` 后再发前进，确认能恢复。
4. 记录现象到 `docs/09`。

## 常见装配错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 上电无反应 | 开关没开、保险丝断、电池没电 | 万用表从电池开始逐段测 |
| 主控反复重启 | 5V 被电机拉低、降压限流 | 分开降压、加电容、降低加速度 |
| 轮子原地打转 | 一侧电机线反接 | 交换该电机两根线，或改固件方向 |
| 超声一直 0 | Trig/Echo 接反、没共地 | 按接线表复查，单独测模块 |
| OLED 不亮 | I2C 地址不对、SDA/SCL 反 | 扫描 I2C 地址，确认 0x3C |
