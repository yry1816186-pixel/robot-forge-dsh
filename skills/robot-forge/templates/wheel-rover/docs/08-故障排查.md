# 故障排查

## 怎么用这一页

先看**症状**，按「最可能 → 次可能」逐条排查；每次只改一个变量，改完复测。不要同时换线、换模块、改代码。

## 症状：上电完全没反应

排查：

1. 电池是否有电？万用表测总电压，低于 6.4V 先充电。
2. 船型开关是否接通？万用表通断档测开关两端。
3. 保险丝是否断？目视或通断档。
4. 降压模块输入是否有电压？测输入电容两端。
5. 5V 输出是否正常？空载测 5.0V ±0.2V。

## 症状：主控反复重启 / OLED 闪烁

排查：

1. 电机启动瞬间掉压：把 5V 与 6V 分开降压，电机端加 470uF 电容。
2. 电池内阻大或电量低：换满电电池试。
3. 杜邦线接触不良：换线，电机线用 22AWG。
4. 固件看门狗：串口日志是否有 brownout 或 rst 原因。

## 症状：轮子不转

排查：

1. 架空时用手转轮子，是否卡死。
2. TB6612 的 STBY 是否拉高（GPIO10）。
3. 电机线是否接在 AO1/AO2、BO1/BO2，而非 VM/GND。
4. PWM 引脚是否有输出：用万用表直流档测平均电压，随命令变化。
5. 电机单独用 1.5V 电池点一下，确认电机本身是好的。

## 症状：前进时原地转 / 方向相反

排查：

1. 一侧电机两根线反了：交换该电机两根线。
2. 固件方向常量与接线不一致：改 `config.h` 的 `LEFT_INVERT`/`RIGHT_INVERT`，重新烧录。
3. 左右轮装反：确认「左轮」是面对车头时的左侧。

## 症状：超声一直显示 0 或 ---

排查：

1. Trig/Echo 是否接反。
2. Echo 分压点电压是否在 3.3V 以内。
3. 模块是否 5V 供电、是否共地。
4. 探头是否被胶带、灰尘挡住；不要贴透明胶。
5. 目标太软（衣服、窗帘）或太斜，超声会读不到；换硬纸板试。

## 症状：30 cm 不停车

排查：

1. 固件是否真的在跑避障逻辑：串口看遥测距离是否变化。
2. 阈值是否被改：`config.h` 的 `STOP_DISTANCE_MM`。
3. 车速是否太快：0.4m/s 时刹车距离约 5cm，加反应时间仍应小于 30cm；地面打滑会变长。
4. 超声安装角度是否朝下/朝上：应水平朝前，离地 5cm 以上。

## 症状：串口打不开 / 找不到设备

排查：

1. USB 线是否只能充电：换一根数据线。
2. 驱动是否安装：设备管理器看是否有未知设备。
3. 串口是否被其他程序占用：关闭串口助手、Arduino IDE、其他 robotd 实例。
4. Windows 用 `--list` 看可用端口；Linux 用 `ls /dev/ttyACM*`，必要时加 udev 规则。

## 症状：遥控延迟大 / 一顿一顿

排查：

1. 主机 CPU 占用高：关掉其他大程序。
2. 串口被日志刷屏：降低日志级别。
3. USB 线太长或质量差：换短一点的数据线。
4. 电池电压低：低于 6.6V 时电机出力下降。

## 症状：驱动或电机烫手

排查：

1. 是否堵转：架空转轮子是否顺畅。
2. 是否长时间满速爬坡/顶墙：降低占空比，加休息。
3. 驱动是否带散热片；不带就贴一块小铝片。
4. 电机是否老化：空载电流明显变大就换电机。

## 还是不行

按顺序记录：电池电压、5V/6V 输出、串口日志、OLED 显示、复现步骤，写到 `docs/09`。带上这些信息再求助，比只说「不转了」有用得多。
