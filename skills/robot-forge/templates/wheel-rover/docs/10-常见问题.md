# 常见问题

## 常见问题

### 我没有电子基础，能装好吗？

能，但前提是愿意按步骤做、会用万用表。接线前先读 [安全与隐私](07-安全与隐私.md)；遇到不确定的线，先断电再查，不要猜。

### 为什么不用 L298N？

L298N 压降约 2V，6V 供电到电机只剩 4V，速度慢、发热大。TB6612FNG 压降小、效率高，价格也只贵几块钱。

### 为什么没有编码器？

编码器会让接线、固件和成本都上一个台阶，违背「两个周末做完」的目标。代价是速度开环、直线会漂；IMU 只修方向，不修速度。

### 可以加摄像头吗？

可以改装，但本版本不包含。加摄像头会改变供电、散热与隐私边界，必须同步更新 `docs/07`、`docs/09` 和 BOM，不能只加一行代码。

### 为什么不能用充电宝供电？

充电宝的 5V 输出在电机启动瞬间会掉压，主控容易复位；而且多数充电宝不支持大电流瞬时输出。用 2S 电池 + 独立降压更稳。

### 电池能用多久？

按 2000mAh、2S、典型负载估算约 3 小时；实际受地面、载重、温度影响。要求至少 30 分钟，低于 6.6V 应充电。

### 车跑偏怎么办？

先确认两侧轮胎气压/摩擦一致、地面平整；再检查 IMU 是否水平安装；最后才调固件的方向修正系数。没有编码器时，跑偏是正常现象，不要期待完全直线。

### 超声在玻璃前面为什么不停？

超声对光滑斜面与玻璃的回波很弱，可能读不到。安全阈值只对硬质、正对的障碍可靠；玻璃门、镜面、窗帘要人工注意。

### 可以室外玩吗？

不建议。本车没有防尘防水，轮胎不适合粗糙路面，电池也不耐暴晒；室外还涉及道路安全与法规。

### 固件烧不进去怎么办？

先只插 USB、不接电池；按住 BOOT 再点 RST 进入下载模式；换一根数据线；确认串口没被占用。仍不行看 [故障排查](08-故障排查.md)。

### 为什么 verify 里有命令显示 SKIP？

没装对应工具（如 PlatformIO）时，非必需命令会跳过，这是设计行为，不是失败；但如果它对应的需求是 must，发布前必须补上证据。

### 这个项目能商用吗？

代码与文档是 MIT，可商用；但电池、充电器、模块的认证与安全责任在你自己。对外销售整机前，需要做电磁兼容、电池运输与消费者安全合规，本模板不提供这些认证。
