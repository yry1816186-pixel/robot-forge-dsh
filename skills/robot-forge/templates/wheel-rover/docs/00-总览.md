# 总览

## 一句话

一台用 2S 电池供电、USB 串口遥控、前方 30 cm 自动停车的两轮差速小车，材料约 ¥261。

## 能力

- **遥控**：电脑键盘控制前进、后退、左右转；松手或按空格立即停。
- **避障**：固件本地判断，30 cm 内连续 3 次触发就停车，不依赖主机。
- **状态**：0.96 寸 OLED 显示电池电压、前方距离、当前模式。
- **修正**：只前进时用 MPU6050 的偏航角速度做方向修正。
- **保护**：心跳超时停车、低电压降速、堵转启发式停机。

## 边界

- 室内平整地面（瓷砖、木地板、短毛地毯）；门槛、长毛地毯、室外路面不保证。
- 没有编码器：速度开环，电量下降后实际速度会变慢；直线长时间仍会漂。
- 遥控距离取决于 USB 线长度，不是无线。
- 避障只测正前方一个扇区，侧面与玻璃、软性物体不可靠。

## 不做什么

- 不做摄像头、不做 SLAM、不做 Wi-Fi/手机 App。
- 不做自制结构件、不做 3D 打印；结构全部买现成底盘套件。
- 不做室外越野，不承诺爬坡。
- 不做医疗、看护、儿童独处场景。

## 系统结构

```text
键盘 → robotd（主机 Python） → USB 串口 → ESP32-S3 固件 → TB6612 → 左右 TT 电机
                                      ├→ HC-SR04（30cm 停车）
                                      ├→ MPU6050（偏航角速度）
                                      └→ OLED（电压/距离/模式）
```

## 术语

| 词 | 意思 |
|---|---|
| 差速 | 左右轮转速不同，从而转弯 |
| 占空比 | PWM 在一个周期里高电平的比例，决定电机平均电压 |
| 堵转 | 轮子被卡住但电机仍在出力，电流大、发热快 |
| 心跳 | 主机周期性发一条命令，固件超时没收到就停车 |
| 开环 | 不测实际转速，只按命令给占空比 |
