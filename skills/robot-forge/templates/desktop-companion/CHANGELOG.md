# 更新记录

本项目遵循语义化版本。版本号同时写在 forge/robot.yaml 的 project.version。

## [0.1.0] - {{DATE}}

### 新增

- 第一版可复现交付：物料清单、接线表、电源预算、外壳 CAD、固件、主机软件、仿真自检、装配与验收文档。
- 固件支持文本协议：表情、头部姿态、灯环、麦克风采集、喇叭播放。
- 主机软件支持模拟串口，拿到硬件之前就能完整演示交互闭环。
- 六项 must 需求都有可执行的验证方式；验证记录写入 forge/evidence.jsonl。

### 已知限制

- 语音识别与合成在主机侧完成，固件只负责音频进出；没有网络时只能用预设短句。
- 外壳按 FDM 打印设计，公差 0.3 mm；光固化或注塑需要改 hardware/cad/dims.json。
- 连续对话需要外接供电；本版本不含电池。

### 尚未验证

- 整机装配、真实房间语音、堵转保护三项需要实物，状态见 docs/09-验证报告.md。没有验证之前不要声称已经跑通。
