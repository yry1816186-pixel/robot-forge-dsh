# 制作计划

## 目标

做出一个放在桌上的陪伴机器人：叫它会转头，摸它有反应，连续运行两小时不重启，默认不联网，材料费不超过 400 元。

## 分阶段

| 阶段 | 做什么 | 完成标志 | 预计 |
|---|---|---|---|
| P0 采购 | 按 docs/01 下单 | 全部到货，型号与清单一致 | 3-7 天（等快递） |
| P1 打印 | 公差块 → 底壳 → 头壳 | 屏幕能压入，螺丝柱不滑牙 | 6 小时 |
| P2 接线 | 按 docs/03 插线，先不装壳 | 串口日志正常，无重启 | 1.5 小时 |
| P3 固件 | 烧录并跑动作自检 | 转头、眨眼、灯环、麦克风都有反应 | 2 小时 |
| P4 软件 | 装 robotd，先模拟后真机 | 叫名字有回应，延迟可接受 | 2 小时 |
| P5 装配 | 装壳、走线、贴脚垫 | 三个检查点全过 | 2 小时 |
| P6 验收 | 按 docs/09 逐条验证 | must 需求全部有证据 | 1 小时 |

## 关键路径

屏幕到货 → 打印头壳（屏幕位公差依赖真实屏幕）→ 接线 → 固件点亮屏幕 → 装配。**先买到屏幕再打印头壳**，不要按标称尺寸盲打。

## 里程碑

1. **M1 裸板能跑**：不装壳，串口能控制两个舵机和屏幕。
2. **M2 能对话**：主机软件模拟模式跑通；接真机后能完成一次「叫名字 → 转头 → 回应」。
3. **M3 能交付**：装配完成，must 需求全部有证据，audit 通过。
