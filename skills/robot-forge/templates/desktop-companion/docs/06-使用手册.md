# 06 使用手册

这份手册写给第一次用的人：拆箱后做什么、平时怎么用、坏了怎么保养。不需要懂代码。

## 第一次使用

### 开箱与放置

1. 把机器人放在平稳、干燥的桌面，背面离墙至少 5 cm，避免喇叭贴着墙产生回授。
2. 电源适配器插在不会踢到的位置，线从桌后走。
3. 不要放在阳光直射处：屏幕会看不清，测距也会被强光干扰。
4. 第一次开机前先读 docs/07 的安全章节。

### 第一次开机

1. 插上 USB-C 电源，等待约 5 秒。
2. 屏幕亮起，出现两只眼睛；灯环亮起淡蓝色；头部缓慢回中。这说明自检通过。
3. 用手在头前方 30 cm 晃一下，眼睛会看向你的手。如果不看，先看 docs/08。
4. 连接电脑，启动主机软件，说「小豆」；它转头并亮起橙色，表示听到了。

第一次开机建议不装外壳先试一遍。确认动作正常再装，拆装会省很多事。

### 让它认识你的声音

默认唤醒词是「小豆」。想换唤醒词需要改主机软件的配置并重新训练唤醒模型，属于进阶操作，见 docs/05。

## 日常使用

### 基本互动

| 你做什么 | 它做什么 | 说明 |
|---|---|---|
| 叫「小豆」 | 转头看你，眼睛变亮，灯环橙色 | 需要主机软件在运行 |
| 摸头顶 | 眯眼，灯环转绿，发出短促的开心声 | 离线也能反应 |
| 摸下巴 | 睁大眼，歪头，灯环变紫 | 表示好奇 |
| 手在 1.5 m 内停留 | 主动抬头 | 光线充足时更可靠 |
| 长时间没人 | 进入待机，呼吸变慢，灯环变暗 | 触摸或声音可唤醒 |
| 说「睡觉吧」 | 闭眼，灯环熄灭，麦克风关闭 | 再叫名字可唤醒 |

### 什么时候它「不聪明」

- 环境太吵（电视、油烟机）时唤醒率会下降，这是单麦克风的本性。
- 一次说太长会截断，建议一句话不超过 15 秒。
- 方言口音重时识别率下降，可在主机软件里换更大的模型。
- 主机软件没启动时，它只会做本地反应，不会回答复杂问题。

### 关机

直接拔电源即可，不需要特殊操作。长期不用建议拔掉适配器，并用防尘布盖住。

## 维护

### 清洁

- 外壳用微湿的无绒布擦，不要用酒精，PETG 会被腐蚀发白。
- 屏幕用眼镜布干擦，不要用纸巾。
- 灯环缝隙用软毛刷，不要用压缩空气，会把灰尘吹进舵机。

### 每月检查

- 手动转头部，确认左右各 45 度无卡顿、无异响。
- 检查螺丝是否松动，尤其是颈部两颗。
- 检查电源线有无破皮、插头有无发热。
- 运行一次自检，确认没有新增报错。

### 每半年

- 给舵机齿轮加一点点塑料齿轮脂（不要用机油）。
- 检查 3D 打印件有无开裂，尤其是螺丝柱。
- 重新跑一次验证，把结果记到 docs/09。

### 更换零件

- 屏幕、舵机、麦克风都是模块化接线，按 docs/03 的接线表替换即可。
- 换舵机后必须重新回中并校准限位，否则可能撞壳。
- 换屏幕后如果颜色不对，检查驱动型号是否一致。

## 进阶玩法

- 换表情：改 firmware/src/face.cpp，重新烧录。
- 换人格：改 software/robotd/personality.py 的规则，不需要重烧固件。
- 加传感器：先在 forge/robot.yaml 里加元件与总线，再跑 check，它会告诉你引脚冲突和电源是否够。
- 改外壳：改 hardware/cad/enclosure.py 的参数，重新导出 STL。

任何改动之后，跑一遍：

~~~bash
python tools/forge.py render
python tools/forge.py check
python tools/forge.py verify
~~~

三项都过再装回去。
