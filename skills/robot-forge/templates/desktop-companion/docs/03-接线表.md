## 电源树

~~~text
5V/3A 适配器
   └── USB-C ──> ESP32-S3 开发板 5V 引脚
                    ├── 板载 LDO ──> 3.3V ──> 屏幕 / 麦克风 / 测距 / 触摸
                    └── 5V 轨 ──> 舵机 x2 / 功放 / 灯环
                                    └── 1000uF 电容并联在入口
~~~

要点：

- 舵机的电源线（红）与地线（棕）直接接到 5V/GND 母线上，不要经过开发板的 3.3V。
- 两个舵机的地、功放的地、开发板的地必须接在一起。只接信号不接地是最常见的「舵机乱抖」原因。
- 1000uF 电容尽量靠近舵机电源入口，正极接 5V，负极接 GND。接反会鼓包。
- 灯环数据线串 330Ω 电阻，电源并联 100nF 电容。
- 麦克风 L/R 引脚接地选左声道，否则会听到两声道混叠。

## 上电顺序

1. 断电状态下插好所有线，用万用表确认 5V 与 GND 不短路。
2. 先只插 USB 给开发板供电（不接舵机），确认串口能识别。
3. 接上 5V 适配器，测量舵机电源入口电压在 4.9-5.1V。
4. 烧录固件，让舵机慢速回中；此时手不要碰头部。
5. 全部正常后再装外壳。

## 接线检查

- [ ] 5V 与 GND 之间电阻大于 1kΩ（未上电）
- [ ] 每个模块的 VCC 电压与标称一致
- [ ] 舵机信号线接在 GPIO15/16，不是电源脚
- [ ] 屏幕 CS/DC/RST 没有接反
- [ ] 麦克风与功放的 I2S 引脚没有互串

## 改引脚

所有引脚都在 forge/robot.yaml 的 buses 与 pins 里定义。改完运行：

~~~bash
python tools/forge.py render
python tools/forge.py check
~~~

检查会拦住 GPIO 冲突、ESP32-S3 保留脚、总线成员引用错误。不要直接改文档里的表。
