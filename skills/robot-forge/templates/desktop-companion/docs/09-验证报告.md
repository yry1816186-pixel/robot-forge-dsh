## 怎么复现

在干净目录里执行：

~~~bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -e software
python -m pip install pytest
python tools/forge.py verify
~~~

应当看到每条命令的退出码。全部 required 命令退出码为 0，才算这一轮验证通过。

## 怎么记录人工证据

装配、手感、噪声这类事没法自动测，用命令记录：

~~~bash
python tools/forge.py evidence --req REQ-005 --level manual ^
  --claim "整机装配 1 小时 52 分完成，两个人都能独立复现" ^
  --note "2026-11-11 张三，按 docs/02 检查点 1-3 全部通过"
~~~

- level 只能是 measured（实测）、manual（人工确认）、simulated（仿真）、assumed（假设）；模型不能替你写 measured 或 manual。
- 只有 measured 与 manual 能让需求变成 ✅；simulated/assumed 最多到 🟡。
- 记录会追加到 forge/evidence.jsonl，带时间戳、来源指纹与不可篡改的历史。改过源码/清单后旧证据会过期，需重跑。
