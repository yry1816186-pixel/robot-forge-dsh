# 07 安全与隐私

这一章不是免责声明，是使用边界。越过边界的玩法，后果需要你自己承担。

## 电气安全

### 市电

本项目使用**成品 5V 电源适配器**，不在项目内处理 220V 市电。这是刻意设计：让没有电工基础的人也能安全上手。

- 只使用有 3C 认证的适配器，不要用劣质充电头。
- 适配器要放在儿童碰不到、不会被水溅到的地方。
- 不要自行拆开适配器，内部电容在断电后仍可能带电。
- 如果你要改成电池供电，必须加保护板与充电管理，且不要无人看守充电。本版本不支持电池。

### 上电与断电

- 插拔任何杜邦线前先断电，带电插拔可能烧 GPIO。
- 上电顺序：先接好所有线，再插 USB，最后开 5V。断电反过来。
- 闻到焦味或看到冒烟，立刻拔电源，不要用手碰。

### 短路与过流

- 5V 与 GND 接反会瞬间烧模块，接线前用万用表确认。
- 电解电容有极性，接反会鼓包甚至爆开。
- 舵机堵转时电流会升到 1A 以上，电源不够会掉压重启。

## 激光（ToF 测距）

- 本项目使用 VL53L0X 一类 **Class 1 激光**测距模块，正常使用下对眼睛安全，但不要直视发射孔，也不要用放大镜/显微镜观察。
- 不要拆开模块外壳：内部激光二极管与驱动电路暴露后不再保证 Class 1。
- 模块只在头部前方短距离测距，不用于扫描或远距测距；不要让儿童把发射孔贴在眼睛上。
- 若更换为其他激光模块（尤其是 Class 2 以上），必须重新评估护目要求，并在此文档补充说明。

## 机械安全

### 运动部件

- 头部转动范围是左右各 45 度、俯仰 -10 到 60 度。固件有软件限位，但**不要用手指强行掰**，会扫齿。
- 上电回中时手离开头部，避免被夹。
- 不要把机器人放在桌边，剧烈动作可能让它移动。

### 堵转

- 头部被卡住超过 5 秒，固件会切断舵机输出并上报 stall。这是保护，不是故障。
- 堵转保护触发后，先排除卡阻，再断电重启。连续触发三次要检查机械结构。
- 不要让舵机长时间顶住外壳，会发热并缩短寿命。

### 限位

- 软件限位写在 firmware/include/config.h，与 forge/robot.yaml 的 mechanical 保持一致。
- 改限位前先手动确认机械上确实能到那个角度，否则软件允许了、结构不允许，还是会卡。
- 装配后先用手转一遍全程，再上电。

## 隐私

### 默认不联网

- 固件不包含 Wi-Fi 代码，也不保存任何音频。
- 主机软件默认 ROBOTD_NETWORK=0，不会主动发起网络请求。
- 只有你显式设置 ROBOTD_BRAIN=external 并提供自己的服务地址，文本才会离开本机。

### 麦克风

- 麦克风只在唤醒或触摸后采集固定时长（默认 8 秒），采集时灯环常亮作为提示。
- 音频在内存中处理，落盘只在你开启调试日志时发生。
- 没有唤醒时，固件仍然在本地做能量检测，但不录音、不上传。

### 数据去向

| 模式 | 音频 | 文本 | 是否出本机 |
|---|---|---|---|
| 本地规则（默认） | 内存 | 内存 | 否 |
| 本地模型 | 内存 | 内存 | 否 |
| 外部大脑（你显式开启） | 内存 | 发送到你配置的地址 | 是，仅文本 |

外部模式下，请确认你信任那个服务，并阅读它的隐私政策。

### 删除数据

项目默认不落盘音频。如果你开过调试日志，删除 logs/ 目录即可。forge/evidence.jsonl 只有命令与结果，不含语音内容。

## 儿童与宠物

- 小零件（螺丝、灯环）有误吞风险，放在儿童拿不到的地方。
- 宠物可能咬线，电源线建议加理线管。
- 不要把机器人当玩具给三岁以下儿童。

## 出问题时

先断电，再排查。不要带电拆机。具体症状见 docs/08-故障排查.md。
