# 05 软件说明

主机软件 robotd 负责「慢思考」：唤醒词、语音识别、对话、语音合成、人格状态。它可以用本地模型，也可以接你自己的 API，但默认完全离线。

## 安装

要求 Python 3.10 以上（推荐 3.11 或 3.12）。不需要 GPU。

~~~bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

python -m pip install -e software
python -m pip install pytest
~~~

音频输入输出使用标准库与可选依赖：

| 能力 | 依赖 | 是否必需 |
|---|---|---|
| 串口通信 | pyserial | 接真机时必需；模拟模式不需要 |
| 麦克风采集 | sounddevice | 真机语音时必需 |
| 播放 | sounddevice | 真机语音时必需 |
| 本地识别 | faster-whisper | 可选，装了才有离线识别 |
| 本地合成 | piper-tts | 可选，装了才有离线合成 |

没装可选依赖时，robotd 会自动降级为「预设短句 + 文本模式」，不会崩。

## 运行

### 先跑模拟模式

不需要任何硬件，用内置的模拟串口走完整闭环：

~~~bash
python -m robotd.main --mock --seconds 20
~~~

它会依次注入「触摸头顶」「有人靠近」两个事件，打印表情变化与回应。这是最快确认软件没坏的方法。

### 接真机

~~~bash
python -m robotd.main --port COM5
~~~

macOS 上是 /dev/tty.usbmodem14101（在终端里用 ls /dev/tty.* 查实际名字），Linux 上是 /dev/ttyUSB0。串口被占用时先关掉 PlatformIO 的监视器。

### 只跑测试

~~~bash
python -m pytest software/tests -q
~~~

## 配置

配置来自环境变量与命令行，优先级：命令行 > 环境变量 > 默认值。

| 变量 | 默认 | 说明 |
|---|---|---|
| ROBOTD_PORT | 空 | 串口设备；为空则进入模拟模式 |
| ROBOTD_NETWORK | 0 | 是否允许联网；默认 0，代码不会主动联网 |
| ROBOTD_BRAIN | rule | rule 或 external；external 时才调用你配置的接口 |
| ROBOTD_BRAIN_URL | 空 | external 模式的接口地址，必须是你自己的服务 |
| ROBOTD_TTS | preset | preset / piper；piper 需要本机安装 |
| ROBOTD_LOG | info | debug / info / warn |

打开 external 大脑前先读 docs/07 的隐私章节：这意味着音频或文本会离开本机，必须由你明确选择。

## 接自己的大模型

robotd 只定义一个很小的接口：

~~~python
class Brain:
    def reply(self, text: str, context: dict) -> str:
        ...
~~~

内置的 RuleBrain 用规则回复，ExternalBrain 通过 HTTP 调用你自己的服务。**API key 不写进固件，也不写进仓库**；放在环境变量或本机配置文件里，并且该文件已在 .gitignore 中。

## 延迟

从说完到机器人开口，推荐目标 1.5 秒内：

- 本地 ASR（faster-whisper small）约 300-600 ms
- 规则回复小于 10 ms；外部大模型取决于网络
- 本地 TTS（piper）约 200-400 ms
- 串口与音频缓冲约 100 ms

超过 2.5 秒用户会觉得「它没听见」，先查串口缓冲区与模型大小。

## 卸载

~~~bash
python -m pip uninstall robotd
~~~

项目目录里的 forge/、docs/、hardware/ 不受影响。
