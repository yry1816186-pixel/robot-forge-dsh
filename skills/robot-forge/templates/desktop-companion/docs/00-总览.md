# 00 总览

## 一句话

一个放在桌上的小机器人：叫它会转头看你，摸它有反应，安静时不吵你，默认不联网。

## 它是什么

{{NAME}} 是一个**可复现的桌面陪伴机器人**。它的核心不是聊天多聪明，而是「有存在感」：你回家它会抬头，你叫它会看过来，你摸它头它会高兴。所有动作都在本地完成，不需要账号，不需要云服务。

它由三部分组成：

- **身体**：3D 打印外壳、两个舵机做的脖子、一块圆屏做眼睛、一个灯环做情绪色。
- **神经**：ESP32-S3 负责实时动作和音频进出，USB 串口连到电脑。
- **大脑**：电脑上的 Python 进程负责语音识别、对话和合成。没开电脑时，身体仍然能待机、能被摸、会转头。

## 能力

- 待机时缓慢呼吸、偶尔歪头，不闪屏、不突然发声。
- 叫名字（默认「小豆」）会转头看过来，给一个高兴的表情。
- 摸头顶与摸下巴有不同反应：头顶是高兴，下巴是好奇。
- 1.5 米内有人停留会主动抬头（可选，受光线影响）。
- 主机软件不在时也能做本地反应；主机在时能完成一次完整对话。
- 默认不联网；麦克风只在唤醒或触摸后采集 8 秒，采集时灯环常亮。

## 边界

这些是它**做不到**的，买之前就要知道：

- 不能走路、不能拿东西。它只有一个两自由度的头。
- 不能脱机对话。语音识别和合成在电脑上，电脑关机就只剩本地反应。
- 不能做人脸识别，也不保存照片或录音。
- 强光直射或玻璃反射会让测距失准，主动抬头可能不触发。
- 连续大音量播放时喇叭会有点破音，这是 3W 小喇叭的物理限制。
- 不支持锂电池。桌面版必须插 5V 电源。

## 不做什么

明确排除，避免范围失控：

- 不做人形、不做双足、不做机械臂。本蓝本的边界是桌面陪伴；其他形态从最近的蓝本派生，走同一套契约。
- 不做云端账号体系，不做 App，不做远程监控。
- 不追求「像人」。像人需要皮肤、表情肌肉、眼神追踪，成本会翻十倍。
- 不在 v1 做电池与充电底座。

数据流只有一条主线：

1. 麦克风采集 16 kHz 单声道音频，固件按 20 ms 一块通过串口送给主机。
2. 主机做唤醒词检测与语音识别，把人话变成文本。
3. 人格模块决定回什么、用什么表情，再把文本交给语音合成。
4. 合成音频回到固件，从喇叭播放；同时固件执行表情与转头。
5. 触摸、测距事件从固件上报，主机据此调整情绪，但本地反应不等待主机。

## 设计取舍

- **两自由度而不是三自由度**：多一个点头轴会多一个舵机、多一份堵转风险，体验提升有限。
- **圆屏而不是方屏**：圆屏更像眼睛，也更容易在外壳上做卡扣。
- **主机侧智能而不是端侧**：ESP32-S3 跑不动像样的语音模型；硬塞进去只会得到一个又慢又笨的版本。
- **默认离线而不是默认联网**：联网功能一旦停服，机器人就变砖。离线能力是底线。
- **先保核心 6 条需求**：任何新功能都不能拖慢「叫它会理你」的响应。

## 术语

- **must / should / nice**：必须做到 / 应该做到 / 有余力再做。只有 must 会在发布审计里卡门。
- **证据级别**：✅ 已跑通（命令或人工确认）、🟡 仅仿真、⚪ 待验证、⛔ 已知问题。
- **生成块**：文档里由 robot.yaml 自动填充的表格或图。手改会被检查发现，改源头再重新生成。
