# 02 组装指南

装配顺序不能乱：屏幕先进头壳，再上舵机，最后合盖。反过来会装不进去。

## 工具

- 3D 打印机（FDM，PETG，0.4 mm 喷嘴）
- 内六角螺丝刀 H1.5 / H2.0
- 电烙铁或压线钳（模块排针需要焊）
- 万用表（至少能测通断和 5V）
- 斜口钳、镊子、热熔铜螺母压入工具（可用电烙铁代替）
- 记号笔与美纹纸（标记线序）

## 打印参数

| 参数 | 建议值 | 备注 |
|---|---|---|
| 材料 | PETG | PLA 夏天会软，ABS 需要封闭腔体 |
| 层高 | 0.2 mm | 外观件可用 0.16 |
| 壁数 | 3 周 | 螺丝柱至少 4 周 |
| 填充 | 15%  gyroid | 不需要更高，外壳主要靠壁 |
| 支撑 | 仅悬垂处 | 屏幕卡扣不要加支撑，会很难拆 |
| 公差 | 0.3 mm | 先打公差试片，再打正式件 |

### 先打公差试片

~~~bash
python hardware/cad/enclosure.py --coupon --out hardware/stl
~~~

试片包含四种孔：M3 通孔 3.4 mm、自攻孔 2.7 mm、热熔螺母孔 4.1 mm、轴承压入孔 22.1 mm。用你的打印机实际打一遍，量出来偏大就整体减 0.1，偏小就加 0.1，改 hardware/cad/dims.json 里的 print_tolerance_mm。

**检查点 1（打印）**：试片上的 M3 螺丝能顺畅穿过，热熔螺母压入后不歪，屏幕卡扣不裂。三项都过再打正式件。

## 步骤

### 步骤 1：焊排针与测试

1. 给 INMP441、MAX98357A、GC9A01、VL53L0X、两个 TTP223 焊排针。焊完用万用表确认没有相邻短路。
2. 不装外壳，只接开发板与屏幕，插 USB 看是否能点亮。
3. 如果屏幕白屏，先查背光（BL）与复位（RST），再查 SPI 模式。

**检查点 2（电气）**：屏幕能显示测试图案，串口日志无重启，5V 与 3.3V 电压正常（4.9-5.1V / 3.25-3.35V）。

### 步骤 2：装屏幕进头壳

1. 从头壳内侧压入屏幕，排线朝下。听到轻微「咔」一声即到位，不要用蛮力。
2. 屏幕四周点四滴中性硅胶，别用 502，会发白。
3. 贴灯环在前壳内侧，灯珠朝外，导线从颈部过孔穿出。

**检查点 3（结构）**：屏幕与外壳齐平，按压不松动；灯环不遮挡屏幕视线；导线能自由穿过颈部。

### 步骤 3：装舵机与颈部

1. 左右舵机（pan）固定在底壳，轴心朝上，舵盘先不要装。
2. 俯仰舵机（tilt）固定在颈部支架，轴心水平。
3. 上电，运行固件自检，让两个舵机慢速回中；回中后再装舵盘。
4. 装舵盘时先用手扶住头，避免舵机受力。

**检查点 4（运动）**：手动转头部无卡死；上电回中时两个轴都动，方向正确；左右各 45 度不撞壳。

### 步骤 4：走线与合盖

1. 舵机线、屏幕排线、灯环线沿颈部线槽走，留 15 mm 余量。
2. 5V 与 GND 用 22AWG 线从底壳引到顶部，和信号线分开走。
3. 在 5V 入口并 1000uF 电容，注意正负极。
4. 合上底盖，四颗 M3x10 对角拧，不要一次拧死。

**检查点 5（整机）**：合盖后无挤压异响；摇晃无零件晃动；插电开机屏幕正常、灯环正常、两个舵机回中。

## 常见装配错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 屏幕压不进 | 打印公差偏小或排线方向反 | 打磨卡扣 0.2 mm，确认排线朝下 |
| 螺丝柱滑牙 | 自攻螺丝拧太紧 | 换 M3 热熔螺母，或换大一号自攻螺丝 |
| 转头卡顿 | 线太短或线槽有毛刺 | 加长线，打磨线槽 |
| 上电重启 | 舵机线太细或电容没焊 | 换 22AWG 线，检查电容极性 |
| 灯环闪烁异常 | 数据线太长或没串电阻 | 数据线缩短到 10 cm，串 330Ω |

## 装完先别急着用

装配完成后先跑一遍验证，确认没有因为装配引入新问题：

~~~bash
python tools/forge.py verify
~~~

然后把检查点照片和实测数据记到 docs/09-验证报告.md。
