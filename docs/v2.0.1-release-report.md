# Robot Forge v2.0.1 发布报告

- 版本：2.0.1
- 日期：2026-11-11
- 状态：补丁发布（Patch Release），修复发布流水线误报
- 适用宿主：DeepSeek Harness（DSH）0.2.x
- 许可证：MIT

## 1. 摘要

v2.0.1 不改变任何生成项目的契约、12 个工具、评分规则、参考手册或蓝本。它只修复插件自身的两个校验器缺陷：这两个缺陷在开发机的 `python -B` 习惯下不可见，但在 GitHub Actions 的干净 Linux 环境中会让 12 个矩阵 job 全部在 “Validate bundle” 步骤失败。

修复后，校验器在**没有 PyYAML 的干净环境**中通过，并且**不会在仓库里留下 `__pycache__`**——后者原本会让校验器自己触发 P071 缓存卫生检查，造成“越跑越失败”的假红。

## 2. 触发问题

GitHub Actions run [43010397993](https://github.com/yry1816186-pixel/robot-forge-dsh/actions/runs/43010397993) 的 12 个 job（Ubuntu/Windows × Python 3.11/3.12/3.13 × Node 22/24）全部失败，失败步骤为 Validate bundle，退出码 1。日志原文：

```text
[ERROR] P021 cordis.patch.yml 解析失败：PyYAML 未安装，跳过 patch 结构解析 cordis.patch.yml
[ERROR] P071 存在缓存目录 .../skills/robot-forge/scripts/forgekit/__pycache__
2 错误 · 0 警告
```

两个根因：

1. **可选依赖被当成硬错误**：bundle 运行时是 stdlib-only，但 `_parse_yaml` 在缺少 PyYAML 时直接报错；GitHub 的 `python` 环境没有预装 PyYAML。 `cordis.patch.yml` 只使用 `yamlmini` 已覆盖的子集，所以这不应阻断发布。
2. **校验器污染自己的检查**：入口脚本导入 `forgekit` 时先生成 `__pycache__`，随后 P071 扫描又把这个刚生成的目录判为错误。本地常用 `python -B`，因此没有暴露。

## 3. 修复内容

| 文件 | 改动 | 作用 |
|---|---|---|
| `skills/robot-forge/scripts/forgekit/validate.py` | `_parse_yaml` 优先 PyYAML，ImportError 时回退到 `yamlmini`；两者都失败才报错 | 干净 CI 环境不再因可选依赖失败；与运行时 stdlib-only 契约一致 |
| `scripts/validate_plugin.py` | 导入 `forgekit` 前设置 `sys.dont_write_bytecode = True` | 校验不生成 `__pycache__`，P071 不再自阻塞 |
| `skills/robot-forge/scripts/validate_plugin.py` | 同上 | 两个入口行为一致 |
| `package.json` / `SKILL.md` / `forgekit/__init__.py` / `CHANGELOG.md` | 版本锁步到 2.0.1 | 满足 P047 四处一致 |
| `README.md` / `docs/acceptance.md` | 安装 URL 与验收版本更新到 2.0.1 | 用户按文档安装到正确版本 |

没有修改：生成项目模板、`robot.yaml` 契约、`verify.yaml` 语义、CST/DSN 规则、六维评分、发布门、12 个工具 schema、11 篇 references。

## 5. 安装与升级

从 2.0.0 升级无需迁移项目；已生成项目的 `forge/robot.yaml`、证据和发布包保持兼容。把 profile 的依赖指向新 tarball、重新安装并重启 Harness 即可：

```bash
dsh plugin --profile desktop add "https://github.com/yry1816186-pixel/robot-forge-dsh/releases/download/v2.0.1/robot-forge-dsh-2.0.1.tgz"
```

仍需把 `robot-forge-dsh` 加入 profile `package.json` 的 `dsh.profile.bundles`，否则 DSH 不会加载 patch。Web 安装方式不变。
